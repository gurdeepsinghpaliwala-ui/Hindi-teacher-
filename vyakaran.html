संधि अभ्यास प्रश्न

1. 'सदा + एव' की सही संधि क्या होगी?
(क) सदाएव    (ख) सदैव    (ग) सदोव    (घ) सादैव
उत्तर: (ख) सदैव
2. 'सूर्योदय' शब्द का सही संधि-विच्छेद चुनिए:
(क) सूर्य + दय    (ख) सूर्यो + दय    (ग) सूर्य + उदय    (घ) सूरी + उदय
उत्तर: (ग) सूर्य + उदय
3. 'प्रति + एक' के मेल से कौन-सा शब्द बनेगा?
(क) प्रत्येक    (ख) प्रतिक    (ग) प्रत्यक    (घ) प्रतिएक
उत्तर: (क) प्रत्येक
4. 'पवन' शब्द का सही संधि-विच्छेद क्या होगा?
(क) पव + न    (ख) पो + अन    (ग) पौ + अन    (घ) पा + वन
उत्तर: (ख) पो + अन
5. 'पुस्तकालय' (पुस्तक + आलय) में कौन-सी संधि है?
(क) गुण संधि    (ख) यण संधि    (ग) दीर्घ संधि    (घ) अयादि संधि
उत्तर: (ग) दीर्घ संधि
6. 'महेश' शब्द का सही संधि-विच्छेद क्या होगा?
(क) मह + ईश    (ख) महा + ईश    (ग) महि + ईश    (घ) मा + हेश
उत्तर: (ख) महा + ईश
7. 'सु + आगत' के मेल से कौन-सा शब्द बनेगा?
(क) सुआगत    (ख) स्वागत    (ग) स्वगत    (घ) सवागत
उत्तर: (ख) स्वागत
8. 'मतैक्य' शब्द का सही संधि-विच्छेद चुनिए:
(क) मत + एक्य    (ख) मति + एक्य    (ग) मतो + एक्य    (घ) माता + एक्य
उत्तर: (क) मत + एक्य
9. 'नयन' शब्द का सही संधि-विच्छेद क्या होगा?
(क) नय + न    (ख) नै + अन    (ग) ने + अन    (घ) नो + अन
उत्तर: (ग) ने + अन

(क) इतिआदि    (ख) इत्यादि    (ग) इतादि    (घ) इत्यदि
उत्तर: (ख) इत्यादि
11. 'हिमालय' शब्द का सही संधि-विच्छेद क्या है?
(क) हिम + आलय    (ख) हिमो + लय    (ग) हिमा + लय    (घ) हिम + लय
उत्तर: (क) हिम + आलय
